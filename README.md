# YOTFARMAX 🤖

منصة شراء واستضافة بوتات ديسكورد تلقائيًا **24/7** — واجهة أمامية تفاعلية بالكامل (محاكاة أمامية).

## المميزات
- 12 باقة بوتات جاهزة (ترحيب، XP، موسيقى، حماية، فارم، تذاكر...)
- صفحة تفاصيل لكل بوت (الأوامر، الملفات، الأحداث، عينة كود)
- بحث وفلاتر حسب التصنيف
- تدفق شراء من 3 خطوات: دفع ← توكن ← استضافة تلقائية
- فحص إيصالات Anti-ChatGPT بـ 25 طبقة
- حفظ البوتات محليًا في المتصفح (localStorage)
- لوحة تحكم محاكاة: RAM / Ping / Uptime / تشغيل وإيقاف وإعادة تشغيل

## تقنيات
- React 18 + Tailwind CSS — ملف HTML واحد مستقل (بدون خوادم)
- مبني من React Artifact single-file

> ملاحظة: هذا الموقع **معاينة أمامية (محاكاة)** — لا يوجد خادم فعلي ولا يتم إرسال التوكنات خارج المتصفح.
